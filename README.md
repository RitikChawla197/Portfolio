# Ritik Chawla — Portfolio

A personal portfolio showcasing my work and projects as a Frontend Developer focused on React & Next.js.

## Tech Stack

- **Framework:** Next.js 15 + TypeScript
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion / Motion
- **Icons:** Lucide
- **Deployment:** Vercel

## Development

```bash
# Install dependencies
npm install

# Run the dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Structure

- `src/app` — routes (`/` home, `/projectspage` all projects)
- `src/components` — sections (Hero, Projects, Experience, Skills, GitHub graph, About, Contact)
- `src/helpers/constants.ts` — project data
- `public/assets` — project media (images & videos) and resume
